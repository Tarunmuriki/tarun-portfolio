# Tarun Portfolio

A dark, creative, responsive portfolio built with React, Vite, TypeScript, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Update project descriptions, links, skills, and internships in `src/data.ts`.
- Update page sections and links in `src/App.tsx`.
- Change colors, layout, and responsive styles in `src/styles.css`.
- Replace the text-based project mockups in `src/App.tsx` with real project screenshots when available.

## Before publishing

1. Verify every project description reflects your actual contribution.
2. Add a real portfolio case study and Figma link if you have one.
3. Add a resume PDF link if you want it downloadable.
4. Test all links and the mobile layout.
5. Deploy the project to Vercel or Netlify.
